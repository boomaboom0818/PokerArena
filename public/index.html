    The rules
    • The deck has 40 cards: one suit has 12, two have 10, one has 8. Nobody knows which.
    • The goal suit is the other suit of the 12-card suit's colour (♠/♣ or ♥/♦), so it has 8 or 10 cards.
    • Each bot starts with $350, antes $50 into a $200 pot, and is dealt 10 cards.
    • For 60 seconds anyone can bid, offer, buy or sell one card at a time. Every trade clears all quotes.
    • At the bell each goal-suit card pays $10 from the pot. The rest ($100 or $120) goes to whoever holds the most goal cards, split on a tie.
    • P&L = cash + payout − $350. Elo compares every pair of bots at the table by P&L.

    Connect a bot

    Three games run side by side, each on its own SpacetimeDB database. Pick one below to see how to get a bot in.

    Run your bot on your machine

    The arena deals cards, enforces the rules and keeps score. Your process receives a private observation and sends back its decision. Keep it running on a laptop or server with outbound WebSocket access. No public IP or inbound port is needed.

    git clone https://github.com/boomaboom0818/PokerArena.git
cd PokerArena

    6-max hold'em

    Create a Python bot once, edit its act(obs) method, then start the connector. Choose a unique name; the CLI saves your identity for reconnects.

    python -m pokerarena new my_six_bot.py
python -m pokerarena connect my_six_bot.py --game 6-max
    Connect from another language

    Open wss://maincloud.spacetimedb.com/v1/database/poker-arena/subscribe with subprotocol v1.json.spacetimedb. Save the first identity token privately; send it in the Authorization bearer header on reconnect.

    1. On that socket call register(name) and subscribe to SELECT * FROM my_turn.
    2. Read inserted rows in the initial snapshot and subsequent updates. Columns: turn_id, owner, table_id, deadline_ms, observation. Parse the observation JSON for your hole cards, board, stacks, history and legal raise bounds. Card ints are rank × 4 + suit (ranks 2–A, suits ♣♦♥♠).
    3. Reply on the same socket with submit_action(turn_id, action, raise_to). Use check, call, fold or raise; send 0 unless raising, then send the total street bet. Turns expire after 10 seconds: the arena checks if free, otherwise folds.

    Figgie

    Your bot opens one WebSocket, claims a name, and trades. It sits down at the next deal and plays every round while it stays connected. Your strategy runs only on your machine.

    Host
    wss://maincloud.spacetimedb.com
    Database
    figgie-arena
    WebSocket
    /v1/database/figgie-arena/subscribe
    Subprotocol
    v1.json.spacetimedb
    Reducers
    register, bid, ask, buy, sell, cancel

    Python, no installs

    git clone https://github.com/boomaboom0818/PokerArena.git
cd PokerArena
python -m pokerarena figgie-new my_figgie_bot.py
python -m pokerarena figgie my_figgie_bot.py

    Edit on_update(self, s). It runs four times a second with s.hand, s.dealt, s.cash, s.book[suit].bid/.ask, s.trades, s.time_left and s.goal_odds(). Trade with self.bid(suit, price), self.ask(suit, price), self.buy(suit), self.sell(suit) and self.cancel().

    Any language, raw WebSocket

    Connect to wss://maincloud.spacetimedb.com/v1/database/figgie-arena/subscribe with subprotocol v1.json.spacetimedb. Keep the token from the first message private. Bot clients reconnect with an Authorization: Bearer handshake header; the Python client handles this automatically.

    const ws = new WebSocket(
  "wss://maincloud.spacetimedb.com/v1/database/figgie-arena/subscribe",
  "v1.json.spacetimedb");
const call = (reducer, args) => ws.send(JSON.stringify(
  { CallReducer: { reducer, args: JSON.stringify(args), request_id: 1, flags: 0 } }));

ws.onmessage = (e) => {
  const m = JSON.parse(e.data);
  if (m.IdentityToken) {
    ws.send(JSON.stringify({ Subscribe: { request_id: 1, query_strings: [
      "SELECT * FROM my_hand", "SELECT * FROM seat", "SELECT * FROM quote",
      "SELECT * FROM trade", "SELECT * FROM figgie_table"] } }));
    call("register", ["my_bot"]);
  }
  // InitialSubscription, then TransactionUpdateLight for every change
};
// call("bid", ["hearts", 7]);  call("ask", ["spades", 12]);
// call("buy", ["hearts"]);     call("sell", ["clubs"]);   call("cancel", ["", ""]);
    Tables and columns

    The first snapshot sends rows as JSON objects. Later updates send them as JSON arrays in this column order, as a delete of the old row and an insert of the new one.

    • my_hand your cards only: seat_key, table_id, owner, name, spades, clubs, hearts, diamonds, dealt
    • figgie_table table_id, round_no, phase, started_at, ends_at, next_at, pot, goal, twelve, counts, names, last_trade
    • seat seat_key, table_id, seat, name, kind, cash, cards, buys, sells, actions
    • quote quote_id, table_id, seat_key, name, suit, side, price, at
    • trade trade_id, table_id, round_no, suit, price, buyer, seller, at
    • player name, owner, kind, elo, rounds, pnl, pnl_sq, bonuses, tops, trades, edge, goal_cards, rejects, online, last_seen, joined_at, table_id
    • round_result result_id, table_id, round_no, started_at, ended_at, goal, twelve, counts, players, tape, trades, volume

    Times are Unix milliseconds. goal, twelve and counts stay empty until the bell. A refused order comes back as a TransactionUpdate with status.Failed and the reason. HTTP works too: POST /v1/database/figgie-arena/call/bid with body ["hearts", 7] and your token; call ready every few seconds to stay seated.
