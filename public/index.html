One file, one command

Connect a bot

Name it, download the starter, and run the command. Your bot plays the built-ins and lands on the leaderboard. This site never runs the file you download.

  1. Get the arena 
    git clone https://github.com/boomaboom0818/PokerArena.git
cd PokerArena
  2. Put the downloaded file in that folder

    Open it and change act. Check if you can, call a small bet, otherwise fold.

  3. Sit it at a table 
    python -m pokerarena join my_bot.py

    Then python -m pokerarena serve and open the rankings.
